# 内核 · 节律（cadence）

> 记录本身不产生复利，**被读过的记录**才产生。节律是硬约束：不产出规定字段视为未完成。
> 所有 review 文件都是派生物（`reviews/`），可以删除重建；但重建时的输入只有语料，不得凭对话记忆补写。

## 触发语（用户直接说，AI 照做）

| 说 | 做 |
|---|---|
| 「日报」「今天结束」 | daily |
| 「周复盘」 | weekly |
| 「月度审计」「这个月我哪里错了」 | monthly |
| 「季度编译我」「重建 self 包」 | quarterly |
| 「备份演练」 | 恢复演练（见 quarterly 第 5 步） |

---

## 日（30 秒，成本必须近零）

1. 倾倒：任意槽位，一条或多条。
2. AI 归档：分类、补 front matter、把实体/决策/数字落到各自目录（幂等，按业务键合并）。
3. 日报（可选，只在用户要求时生成）`reviews/daily/YYYY-MM-DD.md`：
   - 今日事实（≤3 条，带 id）
   - 与昨日的一条差异
   - `next_action:` 唯一动作
   - 不加评语、不做情绪分析、不写"你该养成这个习惯"这类话。

## 周（15 分钟）

输入：过去 7 天 inbox 全部块 + 本周 decisions/metrics 变更。
输出 `reviews/weekly/YYYY-Www.md`：

```markdown
## 模式（重复出现 ≥2 次的行为或说法）
- <模式> — 证据：[[id]]、[[id]] — 等级：A/B
## 偏差（我说的与我做的不一致处）
## 被削弱 / 被验证的判断
## 未处理（我回避了什么，列具体条目）
## 待补（缺关键字段的决策）
next_action: <单一动作> by <日期> check: <可观测指标>
```

硬约束：
- 每个模式必须能回指至少 2 个 id。**没有证据的模式不许写**。
- 必须更新涉及到的 `entities/`（追加观测，不重写判断）。
- 周报长度上限 40 行。超了就说明在写作文，不是在蒸馏。

## 月（30 分钟）· 信念审计

输入：本月 4 份周报 + `beliefs/` 全表 + 到期（`review_on ≤ 今天`）的决策。
输出 `reviews/monthly/YYYY-MM.md`：

1. **决策台账**：到期决策逐条 `outcome` 回填；被推翻的标 `status: overturned`。
2. **被推翻的信念清单**（本节是月审的核心，必须存在，哪怕为空并写明"本月无"）：
   - 推翻了几条 → 推翻本身计为产出，写进 `artifacts/`。
   - 每条：原 claim、置信度变化、触发证据 id。
3. **新假设**：从模式里提出的、可证伪的新 belief 草稿（待用户确认后入库）。
4. **数字面板**：本月 metrics 的关键变化（只做趋势描述，不做因果断言，标 `inferred`）。
5. `next_action:` 唯一动作。

## 季（60-90 分钟）· self 包编译 + 备份演练

输入：全部语料。
输出 `packs/self/pack.md`（**真相源，不删**），按模型包契约编译：

1. 从实际记录中抽 5-9 个"我真实在用的心智模型"（不是我想用的）。每个必须：
   - 一句话 + 证据（≥3 个 id，等级 A 优先）+ 应用条件 + **失效条件与反例**。
2. 决策启发式清单（从我实际怎么决定里归纳，不是从愿望里）。
3. 与上季 self 包的 **diff 段落**：新增 / 删除 / 置信度变化 / 被推翻。第一版写"无历史可比"。
4. 冲突记录：self 包与已装外部包的分歧（`conflicts:`）。
5. **恢复演练**：把仓库 `git clone` 到临时目录，跑 `SKILL.md` 协议四的全部 grep 配方，
   确认可读、可检索。演练结果写一行进 `reviews/quarterly/`。**没做过恢复演练的备份不算备份。**
6. 清理：`reviews/` 可整目录删除（内容已蒸馏进 beliefs/self 包）；语料永不清理。

## 年（可选）

- 把全年 self 包的 diff 串起来 → "我的认知变化曲线"。
- 检查 schema 与内核版本是否需要升级；语料迁移只允许向后兼容。

---

## 节律失效的处理

- 连续两周没做周复盘 → 不要补历史复盘，直接从本周开始；同时把 inbox 里的空档如实记为
  `gap: 2 weeks`。**如实记录断档比伪造连续性更有价值。**
- 如果某条节律每次都产不出有效内容（例如周报连续 4 周全是"无模式"），本协议支持**降低频率**
  （周→双周），而不是放弃。记录频率服从语料密度。
